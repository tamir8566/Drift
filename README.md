# דריפט (Drift)

אפליקציית אנדרואיד אישית למעקב הוצאות: קולטת לבד עסקאות מהתראות גוגל פיי וממסרוני מקס, מסווגת אותן, ומראה כמה נשאר מהתקציב החודשי, לאן הכסף הולך ואיפה אפשר לחסוך. כל הנתונים נשמרים בטלפון בלבד. מסמך הדרישות המלא: [PRD.md](PRD.md).

## התקנה ראשונה

1. נכנסים ל־[Releases](../../releases) במאגר ומורידים את קובץ ה־APK של הגרסה האחרונה (`drift-<מספר>.apk`) לטלפון.
2. פותחים את הקובץ. אנדרואיד יבקש לאשר התקנה ממקור לא מוכר לאפליקציה שממנה פתחתם (דפדפן / קבצים) – מאשרים פעם אחת.
3. פותחים את דריפט. בפעם הראשונה היא תבקש הרשאת התראות (להתראות התקציב והסיכום השבועי).

### הרשאות שחובה לתת כדי שהקליטה האוטומטית תעבוד

נכנסים בתוך האפליקציה ל־**הגדרות** (אייקון שלושת הקווים במסך הבית) ובחלק **הרשאות**:

| הרשאה | למה | איך |
| --- | --- | --- |
| גישה להתראות | קליטת התראות גוגל פיי / ארנק גוגל | לחיצה על "אישור" פותחת את מסך *גישה להתראות* של אנדרואיד – מסמנים את Drift |
| קריאת מסרונים | קליטת מסרוני החיוב של מקס | לחיצה על "אישור" מציגה את חלון ההרשאה של אנדרואיד; אם נדחתה בעבר נפתח מסך פרטי האפליקציה – שם נותנים את ההרשאה SMS |
| התראות מהאפליקציה | התראות 80% / 100% וסיכום שבועי | חלון ההרשאה של אנדרואיד |
| התקנת עדכונים | עדכון עצמי מתוך האפליקציה | מסך "התקנת אפליקציות לא ידועות" של אנדרואיד – מאשרים ל־Drift |

כל שורה מציגה "פעיל" או "חסר", והמצב מתרענן בחזרה מהגדרות המערכת.

### כיול הפענוח

אם מסרון או התראה לא פוענחו (מופיעים כ"לא פוענח" בראש רשימת כל ההוצאות), נכנסים להגדרות → **כיול פענוח**, מדביקים את הטקסט האמיתי, רואים מה המפענח מצא, מסמנים בטקסט את הסכום ואת בית העסק ולוחצים "שמירת תבנית". מכאן והלאה הודעות באותו מבנה יפוענחו לפי התבנית. יומן הניפוי בהגדרות מציג את 20 הטקסטים הגולמיים האחרונים שנקלטו ואת תוצאת הפענוח של כל אחד.

## איך העדכון האוטומטי עובד

- כל דחיפה ל־`main` מריצה את GitHub Actions ([release.yml](.github/workflows/release.yml)): בדיקות יחידה, בניית APK חתום עם `versionCode` = מספר הריצה, העלאה לדלי הציבורי `drift-releases` בסופאבייס (הקבצים `drift-<מספר>.apk`, `drift-latest.apk` ו־`manifest.json`) ויצירת GitHub Release עם תג `v<מספר>`.
- האפליקציה בודקת בפתיחה (עד פעם ביום) את `manifest.json`:
  `https://uabeicwtealqawiwejul.supabase.co/storage/v1/object/public/drift-releases/manifest.json`
  אם `versionCode` במניפסט גדול מהמותקן, מופיע דיאלוג "גרסה חדשה זמינה" עם "עדכן עכשיו" – ה־APK יורד לזיכרון המטמון ונפתח במתקין החבילות של אנדרואיד.
- בדיקה ידנית: הגדרות → עדכון → "בדיקת עדכון" (מוצגים גם שם הגרסה ומספרה).
- כדי שההתקנה מעל הגרסה הקיימת תצליח, כל הגרסאות חייבות להיות חתומות באותו מפתח. לכן יש ליצור את מפתח החתימה פעם אחת ולשמור אותו.

## יצירת מפתח חתימה והסודות במאגר

יוצרים מפתח פעם אחת (מחשב עם JDK; Android Studio מגיע עם `keytool`):

```bash
keytool -genkeypair -v -keystore drift-release.jks -alias drift -keyalg RSA -keysize 2048 -validity 10000 \
  -storepass "<סיסמת-מאגר>" -keypass "<סיסמת-מפתח>" -dname "CN=Drift, O=Tamir, C=IL"
base64 -w0 drift-release.jks > drift-release.jks.b64      # ב־macOS: base64 -i drift-release.jks | tr -d '\n'
```

ב־GitHub: Settings → Secrets and variables → Actions → New repository secret, ומוסיפים:

| סוד | ערך |
| --- | --- |
| `DRIFT_KEYSTORE_B64` | תוכן הקובץ `drift-release.jks.b64` (שורה אחת) |
| `DRIFT_KEYSTORE_PASSWORD` | סיסמת המאגר (`storepass`) |
| `DRIFT_KEY_ALIAS` | `drift` (או הכינוי שבחרתם) |
| `DRIFT_KEY_PASSWORD` | סיסמת המפתח (`keypass`) |

ובנוסף להפצה בסופאבייס:

| סוד | ערך |
| --- | --- |
| `SUPABASE_URL` | `https://uabeicwtealqawiwejul.supabase.co` |
| `SUPABASE_SERVICE_KEY` | מפתח ה־service role של הפרויקט (לא ה־anon) |

ללא ארבעת סודות החתימה הבנייה עדיין מצליחה, אבל ה־APK נחתם במפתח הדיבאג (מתאים לבדיקות מקומיות בלבד – אי אפשר לעדכן ממנו לגרסה חתומה בלי להסיר קודם). שומרים את `drift-release.jks` במקום בטוח; אם הוא אובד, יהיה צורך להסיר את האפליקציה ולהתקין מחדש.

## בנייה מקומית

```bash
./gradlew test            # בדיקות יחידה (מפענחים, סיווג, כפילויות, חישובים)
./gradlew assembleDebug   # APK לדיבאג: app/build/outputs/apk/debug/
./gradlew assembleRelease -PversionCode=42   # חתום במפתח הדיבאג כשאין משתני סביבה לחתימה
```

דרישות: JDK 17, Android SDK (compileSdk 35). לחתימה מקומית אפשר להגדיר את משתני הסביבה `DRIFT_KEYSTORE_PATH`, `DRIFT_KEYSTORE_PASSWORD`, `DRIFT_KEY_ALIAS`, `DRIFT_KEY_PASSWORD`.

## איפה הלוגים

- **בתוך האפליקציה:** הגדרות → יומן ניפוי – 20 הטקסטים הגולמיים האחרונים (מסרונים והתראות) עם המקור, השעה, תוצאת הפענוח ומספר ההוצאה שנוצרה.
- **Logcat:** תגים `Drift.Capture` (קליטה ופענוח) ו־`Drift.Update` (בדיקת עדכון והורדה): `adb logcat -s Drift.Capture Drift.Update`.
- **GitHub Actions:** לשונית Actions במאגר – לוג מלא של כל בנייה, כולל שגיאות העלאה לסופאבייס (הריצה נכשלת אם ההעלאה נכשלה). דוחות בדיקות היחידה מצורפים כ־artifact בשם `unit-test-reports`.

## מבנה הקוד

```
app/src/main/java/com/tamir/drift/
  domain/      קוד טהור (ללא אנדרואיד) עם בדיקות יחידה: parser, classify, dedupe, budget, insights, export
  data/        Room (ישויות, DAO), DataStore (הגדרות), מאגרי נתונים
  capture/     NotificationListenerService, SmsReceiver, CaptureProcessor
  notify/      התראות תקציב, סיכום שבועי (WorkManager)
  update/      בדיקת מניפסט, הורדה והתקנה
  ui/          Compose: theme, components, nav, screens
```
